# Проверка УИН в ГИИС ДМДК

Программа берёт список УИН ювелирных изделий, по очереди проверяет каждый через
публичный сервис Пробирной палаты ([dmdk.ru/check-uin](https://dmdk.ru/check-uin/)) и
собирает всё в Excel:

| УИН | Статус | Статус (как на сайте) | Проверено | … все поля, которые показал сайт (металл, проба, изготовитель, дата) … |
|-----|--------|-----------------------|-----------|---|

Колонка «Статус» приводится к одному из вариантов (в Excel ячейка подсвечивается цветом):

- **В обороте**: изделие числится в обороте (на складе или у продавца);
- **Продано**: реализовано покупателю (розничная продажа);
- **Выведено из оборота**: списано, в переработке и т. п.;
- **Не найден**: сайт не знает такого УИН;
- **Не распознан**: сайт ответил, но формулировку статуса программа не узнала. Смотрите колонки «Статус (как на сайте)» и «Текст ответа»;
- **Ошибка проверки**: сайт не ответил даже после повторов.

На втором листе, «Сводка», посчитано, сколько изделий в каждом статусе.

## Установка (Windows, один раз)

1. Установите Python 3.9 или новее с [python.org](https://www.python.org/downloads/). В установщике
   отметьте галочку **Add python.exe to PATH**.
2. Дважды щёлкните `install.bat`. Он поставит нужные библиотеки и браузер Chromium.

## Запуск

Дважды щёлкните `start.bat`. Откроется окно, где нужно:

1. выбрать файл со списком УИН (`.xlsx`, `.csv` или `.txt`) или вставить УИН в поле, по одному в строке;
2. указать, куда сохранить результат;
3. нажать **«Начать проверку»**.

Где в файле стоят УИН, неважно: программа сама находит в таблице все ячейки с числовыми
кодами. Повторяющиеся УИН проверяются один раз.

### Из командной строки

```bash
python dmdk_checker.py uins.xlsx -o итог.xlsx
python dmdk_checker.py uins.txt --show-browser --delay 3
```

Параметры: `--show-browser` показывает окно браузера, `--delay` задаёт паузу между
запросами в секундах (по умолчанию 2), `--no-resume` запускает проверку заново,
`--input-selector` и `--button-selector` описаны ниже.

## Полезно знать

- **Прерванную проверку можно продолжить.** Результат сохраняется после каждого УИН. Если
  запустить проверку снова с тем же файлом результата, уже проверенные УИН пропускаются,
  а УИН с ошибками проверяются повторно.
- **Капча.** Если сайт начнёт просить капчу, включите «Показывать браузер», введите её
  в окне браузера, и программа продолжит сама. Увеличьте паузу между запросами.
- **Как программа читает сайт.** Она открывает страницу проверки в настоящем браузере,
  вводит УИН, нажимает «Проверить» и забирает ответ двумя способами: перехватывает JSON,
  который сайт получает от сервера, и читает текст, появившийся на странице. Поэтому
  небольшие изменения дизайна сайта ей не мешают. Если после крупного обновления сайта
  программа перестанет находить поле ввода, укажите его вручную:
  `--input-selector "#uin" --button-selector "button.check"`.
- Сайт Пробирной палаты доступен из России. Если запускаете программу из-за рубежа
  или через VPN, сайт может не открыться.

## Проверка без интернета

```bash
python tests/test_mock_site.py
```

Тест поднимает локальную копию-макет страницы проверки и прогоняет на ней всю
цепочку: чтение списка, проверку, распознавание статусов, сохранение в Excel и
продолжение после перерыва.
