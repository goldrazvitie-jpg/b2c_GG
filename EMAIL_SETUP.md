# Отправка подборки на e-mail (Netlify + SMTP)

Форма «Отправить подборку себе» отправляет письмо через Netlify-функцию
`netlify/functions/send-selection.js`, которая коннектится к вашему SMTP.
Пароль хранится только в переменных окружения Netlify — в коде и в браузере
его нет.

## Что уже в репозитории
- `netlify/functions/send-selection.js` — функция отправки (Node + nodemailer).
- `package.json` — зависимость `nodemailer` (Netlify ставит сам).
- `netlify.toml` — публикация сайта + папка функций.
- Форма в `assets/app.js` шлёт POST на `/.netlify/functions/send-selection`.

## Что нужно сделать один раз в Netlify
Site settings → **Environment variables** → добавить:

| Переменная      | Значение (пример)                         | Обяз. |
|-----------------|-------------------------------------------|-------|
| `SMTP_HOST`     | `mail.goldglobe.ru`                       | да    |
| `SMTP_PORT`     | `465` (SSL) или `587` (STARTTLS)          | да    |
| `SMTP_USER`     | `podbor@goldglobe.ru` (полный адрес)      | да    |
| `SMTP_PASS`     | пароль ящика / пароль приложения          | да    |
| `MAIL_FROM`     | `Golden Gift <podbor@goldglobe.ru>`       | нет   |
| `MAIL_TO_OWNER` | ваш адрес для скрытой копии каждой заявки  | нет   |

После добавления переменных сделайте **Redeploy** (Deploys → Trigger deploy),
чтобы функция увидела новые значения.

## Как проверить
1. Пройдите квиз до результата на боевом сайте.
2. «Отправить подборку себе» → введите имя и свой e-mail → «Отправить».
3. Если всё настроено — придёт письмо, а на экране будет «Проверь электронную
   почту…». Если SMTP ещё не настроен — заявка сохранится в Supabase и
   покажется мягкий текст «Мы получили твою заявку…».

## Поведение до настройки
Пока переменные не заданы, функция возвращает `503 SMTP не настроен` —
сайт работает штатно: заявка пишется в `leads`, пользователю показывается
нейтральное сообщение. Ничего не ломается.

## Заметки по провайдерам
- **Свой домен**: хост/порт/логин берутся из панели вашего почтового
  хостинга. Для доставляемости на домене должны быть настроены SPF и DKIM
  (обычно провайдер делает это автоматически).
- Яндекс: `smtp.yandex.ru:465`, пароль приложения из Яндекс.Почты.
- Mail.ru: `smtp.mail.ru:465`, пароль для внешних приложений.
- Gmail: `smtp.gmail.com:465`, включённая 2FA + пароль приложения.

> Из среды разработки реальную отправку проверить нельзя (исходящие SMTP
> заблокированы). Тест — только на задеплоенном сайте Netlify.
