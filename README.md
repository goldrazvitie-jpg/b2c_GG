# GOLDGLOBE / Golden Gift — новая версия квиза

Дизайн взят из вашего файла `Golden_Gift_quiz_v17 (1).html`, база данных и админ-панель —
прежние, без изменений (тот же проект Supabase, те же таблицы products/matrix/result_texts/events/leads).

## Что изменилось по сравнению с прошлой версией

- Новый визуальный дизайн: светлая тема, экран-заставка с фото, отдельный экран отзыва
  перед результатом, анимация «сборки» подборки, расширенный экран результата (о нас,
  упаковка, отзывы, повторная подборка, форма заявки).
- **Найдены и подключены реальные фото всех 30 украшений** — они были зашиты в ваш
  файл дизайна в виде base64, я их извлёк, сжал (было 11 МБ → стало ~1 МБ) и положил
  в `assets/photos/kv01.jpg` … `assets/photos/kv30.jpg`.
- У каждой карточки товара теперь рабочая кнопка «Выбрать» — открывает WhatsApp с
  сообщением, в котором уже указан конкретный артикул.
- Добавлена кнопка «Написать в WhatsApp» и форма «Оставить контакт» в блоке
  «Остались вопросы?» — их не было в исходном дизайн-файле, а без них терялась
  бы часть работающей воронки.
- Все прежние события (`start`, `occasion`, `style`, `budget`, `priority`, `result`, `cta`)
  и заявки (`leads`) по-прежнему пишутся в Supabase — админ-панель и вкладка «Статистика»
  продолжат работать как раньше.

## Как задеплоить

1. Зайдите в Netlify → ваш проект `kvizgg` → Deploys.
2. Перетащите **всю папку `kviz_new`** (со всем содержимым) в область деплоя — так же,
   как деплоили в прошлый раз.
3. Откройте `https://kviz.goldglobe.ru` — должен загрузиться новый дизайн.

## Обязательный шаг после деплоя — обновить фото в базе

Сейчас в базе Supabase поле «Ссылка на фото» у товаров скорее всего пустое
(демо-режим сайта уже покажет фото и без этого шага, но чтобы они появились и в
**рабочей базе** — например, в статистике и в будущем на других экранах, — сделайте так:

1. Зайдите в Supabase → ваш проект → **SQL Editor**.
2. Откройте файл `update_photo_urls.sql` из этого пакета, скопируйте всё содержимое.
3. Вставьте в SQL Editor и нажмите **Run**.

Это пропишет каждому товару ссылку вида
`https://kviz.goldglobe.ru/assets/photos/kv01.jpg` — то есть фото будут открываться
прямо с вашего сайта, без Supabase Storage и без лишних затрат.

⚠️ Выполняйте этот SQL **после** того, как задеплоите новую версию сайта на Netlify —
иначе ссылки будут вести на несуществующие пока файлы.

## Ссылка на товар вместо WhatsApp

У каждого товара теперь можно задать свою ссылку — на карточку товара в вашем
основном магазине, на маркетплейсе и т.п. Если она заполнена, кнопка «Выбрать»
в результате квиза откроет эту ссылку в новой вкладке вместо WhatsApp. Если
оставить поле пустым — кнопка, как и раньше, откроет WhatsApp.

1. Зайдите в Supabase → ваш проект → **SQL Editor**, выполните `add_product_link.sql`
   (добавляет колонку `link` в таблицу `products`, один раз).
2. В админ-панели откройте вкладку **«Товары и цены»** → колонка **«Ссылка на товар»**
   → впишите ссылку для нужных изделий → «Сохранить изменения».

## Что стоит проверить и донастроить

- **Номер WhatsApp.** Сейчас в `assets/app.js` стоит заглушка `79000000000` (в самом
  начале файла, блок `SITE`). Замените на реальный номер компании в формате без
  плюса и пробелов, например `79261234567`.
- Если удобнее принимать заявки в Telegram, впишите username в `SITE.telegram`
  (без @) — тогда все кнопки будут вести в Telegram вместо WhatsApp.
- Админ-панель (`admin.html`) не менялась — вход и все вкладки работают как раньше.
